# 🐞 Web3Hub Bug Report

Welcome to the Web3Hub Bug Report center. If you encounter any bugs, anomalies, or have suggestions for improvement during use, please submit an Issue here.

## 🛠 How to Submit Feedback

1. **Search Existing Issues**: Before submitting a new one, please search to see if there's a similar feedback already to avoid duplicates.
2. **Use the Template**: Please click [New Issue](https://github.com/leecho/web3hub-bug-report/issues/new) and choose the appropriate template (Bug or Feature Request).
3. **Provide Detailed Information**: The more detailed the information, the faster we can fix it.

---

## 📝 Bug Report Template

When submitting a bug, please try to include the following information:

### 1. Problem Description
Briefly describe what problem occurred.

### 2. Reproduction Steps
1. Open the page `https://web3box.vercel.app/...`
2. Click the `...` button
3. Input `...`
4. Observed `...`

### 3. Expected Behavior
What was the outcome you expected to see?

### 4. Actual Behavior
What actually happened? (Please paste any error messages)

### 5. Environment Information
- **Browser**: (e.g., Chrome 124, Safari)
- **Wallet**: (e.g., MetaMask, Phantom, OKX Wallet)
- **Network**: (e.g., Ethereum Mainnet, Solana Mainnet)
- **Device**: (e.g., MacBook Pro, iPhone 15)

### 6. Screenshots/Screen Recording (Optional)
If possible, please upload images or GIFs to help us understand the problem intuitively.

---

## 🛡 Security Vulnerabilities

If you discover a serious vulnerability that could jeopardize user asset security or privacy, **please do not submit an Issue publicly**.

Please contact us privately via:
- **Email**: leecho571@gmail.com

We will prioritize security-related feedback and express gratitude to effective vulnerability reporters.

---

## 💡 Feature Suggestions

If you have better ideas or want us to support new chains/tools, you are also welcome to submit a [Feature Request](https://github.com/leecho/web3hub-bug-report/issues/new).

Thank you for helping Web3Hub become better! 🚀
