# 🐞 Web3Hub 问题反馈

欢迎来到 Web3Hub 的问题反馈中心。如果您在使用过程中遇到任何 Bug、异常或有改进建议，请在此提交 Issue。

## 🛠 如何提交反馈

1. **搜索已有 Issue**：在提交新问题前，请先搜索是否已有类似的反馈，以避免重复。
2. **使用模板**：请点击 [New Issue](https://github.com/leecho/web3hub-bug-report/issues/new) 并选择合适的模板（Bug 或 Feature Request）。
3. **提供详细信息**：信息越详细，我们修复的速度就越快。

---

## 📝 Bug 反馈模板

提交 Bug 时请尽量包含以下信息：

### 1. 问题描述
简要描述发生了什么问题。

### 2. 复现步骤
1. 打开页面 `https://web3box.vercel.app/...`
2. 点击 `...` 按钮
3. 输入 `...`
4. 观察到 `...`

### 3. 预期行为
你期望看到的结果是什么？

### 4. 实际行为
实际上发生了什么？（如有报错信息请粘贴）

### 5. 环境信息
- **浏览器**：(例如 Chrome 124, Safari)
- **钱包**：(例如 MetaMask, Phantom, OKX Wallet)
- **网络**：(例如 Ethereum Mainnet, Solana Mainnet)
- **设备**：(例如 MacBook Pro, iPhone 15)

### 6. 截图/录屏 (可选)
如果可能，请上传图片或 GIF 以帮助我们直观理解问题。

---

## 🛡 安全漏洞 (Security Vulnerabilities)

如果您发现了可能危及用户资产安全或隐私的严重漏洞，**请不要公开提交 Issue**。

请通过以下方式私下联系我们：
- **Email**: leecho571@gmail.com

我们会优先处理安全相关的反馈，并对有效的漏洞报告者表示感谢。

如果您有更好的想法或希望我们支持新的链/工具，也欢迎提交 [Feature Request](https://github.com/leecho/web3hub-bug-report/issues/new)。

感谢您帮助 Web3Hub 变得更好！🚀
